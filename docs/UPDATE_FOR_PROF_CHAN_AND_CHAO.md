# Update for Prof. CHAN and Chao

I prepared `hermes-textstats` version `0.1.1` as a more useful DIVE-ready
writing analysis package. The update adds text-file input, a Markdown report
format for notebook/screenshot use, paragraph count, longest sentence length,
and lexical diversity, while keeping the original Python API and command-line
workflow simple. The package materials now include a sharper one-line summary,
a stronger motivation paragraph, an achievements list, and a compact showcase
screencap designed to remain readable even when shrunk.

PyPI: https://pypi.org/project/hermes-textstats/

Showcase image: `docs/assets/hermes-textstats-showcase.png`
